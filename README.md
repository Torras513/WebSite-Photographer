# 📸 Portfólio de Fotografia - Rodrigo Rosa

## 🌟 Sobre o Projeto
Este é o portfólio oficial de **Rodrigo Rosa**, um entusiasta da fotografia apaixonado por capturar a essência de momentos, paisagens e a estética do mundo automóvel. O site foi desenvolvido para servir como uma galeria visual de alta qualidade, permitindo que clientes e entusiastas explorem diferentes categorias de fotografia, desde eventos de carros até sessões de retratos e paisagens naturais.

## 🚀 Funcionalidades Principais
- **Galeria de Portfólio:** Organizada por categorias (Carros, Sessões de Fotos, Paisagens e Objetos).
- **Sistema de CRM:** Área dedicada para gestão de clientes e organização de projetos.
- **Área de Login:** Sistema de autenticação para acesso restrito a funcionalidades específicas.
- **Design Responsivo:** Experiência fluida em dispositivos móveis, tablets e desktops.
- **Integração Direta com WhatsApp:** Facilita o contacto imediato com o fotógrafo.

## 🛠 Tecnologias Utilizadas
- **HTML5:** Estrutura semântica e moderna.
- **CSS3:** Estilização personalizada com foco em design limpo e elegante.
- **JavaScript:** Interatividade, manipulação de menus e lógica de autenticação.

## 📸 Categorias de Fotografia
- 🏎️ **Eventos de Carros:** Capturas dinâmicas de encontros e exposições.
- 👤 **Sessões de Fotos:** Retratos profissionais e sessões temáticas.
- 🏞️ **Paisagens e Objetos:** A beleza do horizonte e detalhes do cotidiano.

## 🚀 Como Executar
Para visualizar o projeto localmente, basta abrir o ficheiro index.html no seu navegador ou utilizar um servidor local (como o Live Server do VS Code).

Para produção, o site já está configurado e disponível no servidor LXC.
